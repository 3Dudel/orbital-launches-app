# 🚀 Orbital Launches App

Moderne Web-App (PWA-Stil) für die nächsten orbitalen Raketenstarts.

- **Starts**: Liste mit ausklappbaren Details, Suche und Filter
- **Karte**: Startplätze weltweit (Leaflet + OpenStreetMap)
- **Startplätze**: Datenbank mit den wichtigsten Kosmodromen
- **Menü (⋮)**: Hell/Dunkel/Auto, Zeitzone (lokal/UTC), Info
- Untere Tab-Leiste wie in einer nativen App

## Daten aktualisieren

Die Starts stehen in `data/launches.js`, die Startplätze in `data/sites.js`.
Quelle: [Wikipedia – Liste geplanter orbitaler Raketenstarts](https://de.wikipedia.org/wiki/Liste_geplanter_orbitaler_Raketenstarts).
Termine sind vorläufig und können sich jederzeit verschieben.

## Lokal starten

Einfach `index.html` im Browser öffnen.
